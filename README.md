# Make CMD feel like the linux terminal!
## Downloads are in [Releases](https://github.com/realc0mpl3x/linux-aliases/releases)
Ever wanted to feel or larp as a linux nerd? Or maybe you switched to Windows for some reason because of an inconvenience in Linux?

Download this pack, unzip, run setup.cmd and in a split second you have over 170 linux commands in your Command Prompt!

I do have to say, i did use ai for this. I did make some commands, but not many. AI made like 150+ of them, so be aware.
